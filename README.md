# Python SI 01

Repositório de estudos da disciplina **Lógica de Programação**, do curso de **Sistemas de Informação**. Aqui estão os exercícios feitos em aula, as atividades práticas e os mini projetos desenvolvidos em Python.

## O que estou praticando

- lógica de programação, entrada e saída de dados;
- condicionais (`if`, `elif` e `else`);
- laços de repetição (`for` e `while`);
- strings, listas, dicionários e funções;
- validação de dados e tratamento de situações comuns;
- leitura e gravação em arquivos de texto;
- organização de programas em módulos;
- interfaces gráficas com `Tkinter`;
- operações de cadastro, consulta, alteração e exclusão (CRUD).

## Como executar

É necessário ter o **Python 3** instalado. No terminal, entre na pasta do arquivo e execute, por exemplo:

```bash
python3 adivinha.py
python3 aula-jogo-forca/jogo.py
python3 trabalho23-06/main.py
```

Os projetos que usam `Tkinter` podem precisar do pacote de interface gráfica da distribuição Linux. Em sistemas baseados em Debian/Ubuntu:

```bash
sudo apt install python3-tk
```
